# Bitcoin Address Generator

This project generates random Bitcoin private keys and derives wallet data using the secp256k1 curve.

## Features

- Generates a random 32-byte private key
- Derives a compressed Bitcoin public key
- Creates a Bitcoin address in Base58Check format
- Exports the wallet in WIF format
- Includes a Flask web interface for generating wallet data in the browser
- Generates multiple wallets at once
- Validates Bitcoin addresses
- Shows QR codes for each address
- Supports CSV export of generated wallets
- Includes copy-to-clipboard actions
- Includes a light/dark theme toggle

## Requirements

Python 3.9+

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the script

```bash
python bitcoin_address_generator.py
```

## Run the web app

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000/
```

## Important

This is an educational project for learning Bitcoin address generation. It is not a production wallet and should not be used to store real funds.

## File Structure

- `bitcoin_address_generator.py` — wallet generation logic
- `app.py` — Flask web application
- `templates/index.html` — front-end UI
- `requirements.txt` — Python dependencies
